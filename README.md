# dotfiles

- 💻 Framework 16
- 🐧 CachyOS + Niri window manager
- 🌛 Noctalia theme https://noctalia.dev
- 🔗 mise bootstrap is choice 😚🤌

# installation

1. :waves hands:: install git
2. install mise `curl https://mise.run | sh`
3. run:

```shell
mise bootstrap \
  --from-dir ~/.dotfiles \
  --from https://github.com/defeated/dotfiles
```
